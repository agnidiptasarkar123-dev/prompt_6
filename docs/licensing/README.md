# HawaSaathi Licensing & Legal Compliance Framework

## 1. First-Party Application Code
- **License:** Apache License 2.0 (`Apache-2.0`)
- **SPDX Identifier:** `Apache-2.0`
- **Text:** Full license text is available at [LICENSE](file:///Users/agnidiptasarkar/Desktop/prompt_6/LICENSE).
- **Scope:** Covers all first-party application software, source code, schemas, mathematical engines, algorithmic routines, and test suites authored within the HawaSaathi repository.
- **Header Notice:** Every first-party source file in `src/` carries the SPDX identifier:
  ```typescript
  // SPDX-License-Identifier: Apache-2.0
  ```
- **Trademark Notice:** The Apache-2.0 license grants permissions for software use and modification; it explicitly does NOT grant trademark rights in the HawaSaathi name, logos, or associated brand elements.
- **Third-Party Exclusions:** Apache-2.0 applies strictly to first-party code; it does NOT apply to third-party datasets, external API feeds, official government reports, map cartography, or bundled libraries.
